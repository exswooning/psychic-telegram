Mail carried by

Mail is the biggest slice of a migration and the only one behind a write ceiling Google will not raise (3/sec/account). DMS hands the job to Google instead. One choice, not two switches: both would copy every message twice, neither would migrate mail at all. Choosing DMS takes Gmail out of the engine run automatically — then use the “Start Google DMS mail import” action below.

A Drive link names a file by id, and copying mints a new one — so every link in migrated mail points at the source file and dies with the source tenant. This repoints the ones in mail we migrate. Drive must run before Gmail or the migration refuses to start, because a message already inserted is never re-examined.
